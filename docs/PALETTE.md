Every colour below carries its contrast ratio against its own flavour's `base`,
measured per WCAG 2.1. Accents and text tones are all at or above 4.5:1, which
is the AA threshold for body text.

## Roles

The role names come from Catppuccin, so a port written for one scheme maps onto
the other without renaming anything.

| Role | Use it for |
| --- | --- |
| `base` | The editor field. |
| `mantle` | Chrome behind the field: status lines, tab bars, footers. |
| `crust` | The outermost layer: window borders, inactive chrome. |
| `surface0` … `surface2` | Raised surfaces: floats, popups, selections, the cursor line. |
| `overlay0` … `overlay2` | Dimmed text: comments, line numbers, inactive UI, whitespace marks. |
| `subtext0`, `subtext1` | Secondary text: labels, hints, doc comments. |
| `text` | Primary foreground. |
| `red` | Errors, deletions, dangerous keywords. |
| `orange` | Numbers, constants, warnings. Also ANSI index 16. |
| `yellow` | Types, classes, search matches, the cursor. |
| `green` | Strings, additions, success. |
| `aqua` | Functions, methods, git changes. |
| `blue` | Identifiers, properties, links. |
| `purple` | Keywords, operators, punctuation with meaning. |
